# Model AI trên Raspberry Pi

- Model mặc định: `best.pt`
- Đường dẫn từ gốc repository: `deploy/pi/models/best.pt`

Model thuộc tiến trình controller camera/cảm biến, không thuộc container giao diện web. Giữ tên và đường dẫn này ổn định để controller có thể cấu hình bằng một biến `MODEL_PATH` sau này.
